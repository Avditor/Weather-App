I built a sleek and responsive weather app using **React, JavaScript, and Vite** for fast performance and efficient development. The app fetches real-time weather data from an API, displaying **temperature, min/max temperature, and weather** for any searched location. It features a clean **UI with dynamic icons**, background changes based on weather conditions, and a smooth **user experience**. I used **React Hooks** for state management and **Axios** for API requests. The app is fully responsive, ensuring usability across devices. With **Vite**, the build is optimized for speed.
